# Password Strength Checker

A Java application that analyzes password security and classifies passwords as Weak, Medium, or Strong.

## Features

* Checks password length
* Detects uppercase letters
* Detects lowercase letters
* Detects numeric characters
* Detects special characters
* Classifies password strength

## Technologies Used

* Java
* Object-Oriented Programming

## Sample Output

Enter Password: Hello@123

Password Analysis:

Strength: STRONG
